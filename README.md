## 📂 Project Structure & Portfolio Suite

### 1. Genomic Variant Calling & Filtering Pipeline (`scripts/` or local backend)
* **Description:** A command-line bioinformatics engine designed to process raw variant call data, filter low-quality sequencing artifacts, and extract functional annotations.
* **Tech Stack:** Python, Bash, Pandas, Regular Expressions.

### 2. Interactive Variant Analysis Dashboard (`app.py`)
* **Description:** A dynamic Streamlit web application built for researchers to upload, filter, and visualize genomic variants through an interactive browser interface.
* **Tech Stack:** Python, Streamlit, Pandas, NumPy, Matplotlib.

### 3. RNA-Seq Differential Expression & Volcano Plot App (`app_rnaseq.py`)
* **Description:** A full-stack transcriptomics pipeline that computes gene expression fold changes, executes statistical row-wise independent t-tests across replicates, generates publication-ready Volcano plots, and exports flagged gene lists.
* **Tech Stack:** Python, SciPy, Pandas, NumPy, Matplotlib, Streamlit.
