## 📂 Backend Project Structure 

### 1. Genomic Variant Calling & Filtering Engine (`rnaseq_csv_pipeline.py` & scripts)
* **Description:** A command-line bioinformatics engine designed to process raw genomic data, filter low-quality sequencing artifacts, and extract functional annotations.
* **Tech Stack:** Python, Pandas, Regular Expressions.

### 2. Interactive Variant Analysis Dashboard (`app.py`)
* **Description:** The source code for the live variant Streamlit web application.
* **Tech Stack:** Python, Streamlit, Pandas, NumPy, Matplotlib.

### 3. RNA-Seq Differential Expression & Volcano Plot App (`app_rnaseq.py`)
* **Description:** The source code for the live transcriptomics pipeline and visualization app.
* **Tech Stack:** Python, SciPy, Pandas, NumPy, Matplotlib, Streamlit.
